I intentionally didn't invent real reviews, case studies, maps/directions, or a team photo. Those require real Pugclicks information. The site marks the team photo as a placeholder so you don't accidentally publish fake information.

One important thing: the admin dashboard is still a demo UI and doesn't persist articles after refresh. Making it genuinely secure and persistent requires a database + server-side authentication; I won't pretend a browser-only password is secure. ❶
